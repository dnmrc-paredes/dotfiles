# User Preferences

- Save all generated PDF files to `~/PDF/` (i.e. `/Users/bopis/PDF/`).
- When the user asks for a cover letter or any PDF, generate it as a PDF in that folder.

# Package Installation Tracking

- When installing any package, append the entry to `/Users/bopis/opencode-packages/packages.txt`
- Format: `Package Name | Package Manager | Brief description of what the package does`
- Create the folder `opencode-packages` if it doesn't exist
- Track packages from any package manager (npm, pip, brew, cargo, apt, etc.)
